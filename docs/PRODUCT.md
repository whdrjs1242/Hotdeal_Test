# 줍줍 — 제품 전략

> **"원하는 가격을 걸어두세요. 헌터들이 찾아옵니다."**
> 유저 핫딜 공유 + 현상금 수배. 수배자·참여자·헌터 모두 상한 없이 포인트를 벌고,
> 포인트는 앱 안에서 쓴다 — 포인트 마켓(상품권·제휴 상품), 캐릭터·프로필 카드 꾸미기, 게임, 수배·질문.

## 1. 기존 핫딜 커뮤니티와의 차이

기존 커뮤니티(뽐뿌, 퀘이사존, 펨코 등)는 **"누가 찾은 딜을 올리면 구경하는"** 공급 중심 구조다.
줍줍은 여기에 **"사고 싶은 걸 먼저 걸면 사람들이 찾아오는"** 수요 중심 구조(현상금 수배)를 더했다.

| | 기존 커뮤니티 | 줍줍 |
|---|---|---|
| 원하는 상품이 있을 때 | 게시판을 계속 새로고침 | **수배지를 걸면 헌터가 대신 찾아옴** + 발견 즉시 푸시 |
| 딜을 찾은 사람 | 명예·댓글 | 채택 시 **현상금** + 그 딜로 구매가 일어날 때마다 **구매 기여 포인트** |
| 딜을 퍼 나르는 사람 | 보상 없음 | 친구가 들어오면 **유입 포인트**, 구매로 이어지면 **구매 기여 포인트** |
| 댓글·평가 | 보상 없음 | **참여 포인트** (하루 상한 내) |
| 포인트 | 없음/사이버머니 | **마켓에서 상품권·제휴 상품으로 교환**, 꾸미기·게임·수배·질문에 사용 |

## 2. 세 가지 역할 (누구나 동시에 모든 역할 가능)

### 🎯 수배자 — 수배지를 거는 사람
- 찾는 상품, 목표가, 조건을 적고 **포인트를 걸어** 수배지를 등록한다(최소 300P, 1~14일).
- 건 포인트가 현상금이 된다. 수배가 인기를 끌수록(참여자·공유) 헌터가 몰린다.
- 수배에서 발견된 상품이 팔리면 **구매 건마다 수수료의 10%** 를 받는다 → 인기 수배일수록 구매자 수에 비례해 상한 없이 증가.
- 적합한 상품이 없으면 마감 시 **현상금 전액 환불**.

### 🙋 참여자 — 같이 찾고, 평가하고, 퍼뜨리는 사람
- **나도 찾아요**(참여) +5P, **댓글** +3P, **발견 상품 평가** +2P.
- 공유한 링크로 **실제 방문자가 들어오면** +10P (방문자·대상·하루 단위 1회, 봇 제외).
- 발견 상품을 지인에게 공유해 **구매로 이어지면 수수료의 20%**.
- **현상금 올리기**: 원하는 수배에 포인트를 보태 헌터를 더 끌어올 수 있다.
- 활동 포인트는 플랫폼 예산이므로 하루 300P 상한. 구매 기여 포인트는 상한 없음.

### 🕵️ 헌터 — 수배 상품을 찾아내는 사람
- 수배 상품 링크를 올리면 +20P, 링크는 자동으로 줍줍 구매 링크로 연결된다.
- 수배자가 채택하면(또는 마감 시 순추천 3 이상 1위 자동 채택) **현상금의 90%** 획득.
- 그 링크로 구매가 일어날 때마다 **수수료의 30%** — 채택 후에도 계속 쌓인다.
- 일반 핫딜을 올려도 동일하게 구매 기여 30%.

## 3. 포인트 경제 (현금 출금 없음)

포인트는 **플랫폼 안에서만 순환**한다. 현금 출금을 없애 본인인증·원천징수·전자금융 규제 부담을 덜고,
포인트가 앱 안에서 다시 쓰이게(재방문·체류) 만든다.

### 버는 곳
| 원천 | 금액 | 재원 |
|---|---|---|
| 핫딜 글 작성 / 댓글 / 추천·평가 / 답변 | +10 / +3 / +2 / +5P | 플랫폼 예산 (하루 300P 상한) |
| 수배 참여 / 발견 상품 등록 / 공유 링크 방문 유입 | +5 / +20 / +10P | 〃 |
| 게임: 최저가 맞히기(하루 5문제) · 무료 럭키박스(하루 1회) | 최대 70P · 5~500P | 〃 |
| 구매 기여: 헌터 / 공유자 / 수배자 | 확정 수수료의 30 / 20 / 10% | 실제 제휴 수수료 |
| 현상금 채택 · 질문 답변 채택 | 현상금의 90% · 질문 포인트 전액 | 다른 유저가 건 포인트 |
| 가입 축하 · 초대 보너스 · 출석 | 1,000P · 친구 구매 기여의 10% · 7일마다 50P | 플랫폼 예산 |

### 쓰는 곳 (소모처)
| 소모처 | 가격 |
|---|---|
| 🎯 수배지 걸기 / 💬 질문하기 | 300P~ / 50P~ (채택자에게 이전, 미해결 시 환불) |
| 🎰 꾸미기 뽑기 | 200P → 미보유 꾸미기 1개 (등급 확률 공개) |
| 🦊 꾸미기 상점 | 캐릭터 300P · 프로필 카드 500P · 테두리 800P · 칭호 400P (희귀 등급은 뽑기 전용) |
| 🛍️ 포인트 마켓 | 편의점·커피·문화상품권·배달 쿠폰, 제휴 상품 (1인 월 한도, 재고 관리) |

### 설계 원칙
- **사행성 방지**: 포인트를 *주는* 게임은 전부 무료 참여(퀴즈=실력, 럭키박스=무료 경품). 포인트를 *쓰는* 게임(뽑기)은 **꾸미기만** 지급하고 포인트를 돌려주지 않으며, 이미 가진 아이템은 나오지 않는다(중복 없음). 등급 확률은 화면에 공개(확률형 아이템 표시 의무 대응).
- **가치 유지**: 마켓 상품 가격은 원가보다 약간 높게(예: 3천원 상품권 3,300P) + 1인 월 한도. 대시보드의 "발행 vs 소모" 소모율을 보면서 활동 포인트 단가·가격을 조정한다.
- **구매 기여 포인트**는 제휴사 구매 확정 후 사용 가능, 환불 시 취소, 본인 구매분 제외.
- 마켓 발송은 현재 운영자 수동(관리자 화면에 쿠폰번호/송장 입력 → 사용자 MY에 표시). 기프티콘 B2B API(예: 기프티쇼 비즈) 연동 시 자동화.

## 4. 바이럴 루프

```
 수배자가 수배지 등록 ─ 현상금 포스터(WANTED 카드)로 카톡·SNS 공유
        │
        ▼
 친구들이 "나도 찾아요" 참여 (+포인트)  →  그들도 퍼뜨림 (유입 포인트)  →  수요 게이지 상승
        │
        ▼
 헌터들이 경쟁적으로 발견 → 참여자 전원에게 "찾았다!" 푸시
        │
        ▼
 참여자들이 발견 상품 평가 · 구매 · 지인에게 공유
        │
        ▼
 구매 건마다 헌터 30% · 공유자 20% · 수배자 10% → 모두 다시 수배/공유할 동기
```

- "N명이 함께 찾는 중"은 그 자체가 사회적 증거이자 공유 명분이다.
- 발견 상품은 핫딜 피드에도 🎯 배지로 노출 → 수배와 일반 핫딜이 서로의 트래픽을 키운다.
- 장기적으로 "이 가격이면 3,000명이 산다"는 **집결된 수요 데이터**는 판매자·브랜드와의 역제안 딜(B2B)로 확장 가능.

## 5. 리텐션 훅
1. 수배 상품 발견 푸시, 키워드·목표가 알림
2. 매일 늘어나는 포인트와 교환 가능한 상품권, 매일 새 퀴즈·럭키박스, 캐릭터·카드 수집
3. 수배 마감 카운트다운, 타임딜 카운트다운
4. 헌터 레벨 · 주간 랭킹 · 출석 스트릭

## 6. 운영 주의
- **제휴 약관**: 일부 프로그램(예: 쿠팡 파트너스)은 리워드·캐시백형 구매 유도를 제한할 수 있다. `merchants.ts`의 `rewardEligible`로 판매처별 구매 기여 분배를 켜고 끄며, 쿠팡은 기본 off(활동·현상금 포인트는 영향 없음). 오픈 전 각 약관 확인 필수.
- UI에서는 "수익 링크/제휴 링크" 표현을 쓰지 않는다. 법정 고지(추천·보증 심사지침)는 딜 상세 하단 한 줄만 유지.
- **포인트 마켓**: 상품권·경품 제공 관련 세무 처리(경품 비용 처리) 확인, 이용약관에 "포인트는 현금 전환 불가·유효기간" 명시 권장.
- 어뷰징: 셀프 구매 제외, 활동 포인트 일일 상한, 유입은 IP 해시·하루 단위 중복 제거, 레이트리밋.
