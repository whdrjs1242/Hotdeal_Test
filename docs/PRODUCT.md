# 줍줍 — 제품 전략

> "핫딜을 줍고, 나누고, 함께 번다"
> 커뮤니티 핫딜 게시판 + 공유하면 수익을 나눠주는 구조 + 크리에이터용 link-in-bio SaaS를 합친 모바일 앱

## 1. 기존 서비스와 무엇이 다른가

| | 기존 핫딜 커뮤니티 (뽐뿌, 퀘이사존, 펨코 핫딜 등) | 줍줍 |
|---|---|---|
| 딜을 올리는 사람 | 명예 / 댓글이 보상 | **명예 + 실제 수익** (내가 올린 딜 구매 수수료 20%) |
| 딜을 퍼 나르는 사람 | 보상 없음. 오히려 제휴 링크는 금지 | **퍼 나를수록 돈이 됨** (내 공유 링크 구매 수수료 30%) |
| 인플루언서 | 쿠팡 파트너스를 따로 가입하고 링크를 하나씩 수동 생성 | **링크만 붙여넣으면 자동 수익화** + `jupjup.kr/@내채널` 페이지 제공 |
| 알림 | 게시판을 계속 새로고침 | **키워드 + 목표가 푸시** ("에어팟 20만원 이하") |
| 정보 신뢰도 | 댓글 판단 | **딜 온도(°C)**, 품절 신고 3건이면 자동 종료, 가격 히스토리 |

핵심 발상: **"공유"를 사용자의 수익 활동으로 바꾼다.** 사용자는 자기 돈을 벌려고 카톡방, 맘카페, 인스타에 딜을 퍼 나르고,
그게 곧 플랫폼의 무료 마케팅이 된다. 플랫폼은 제휴 수수료의 절반 가량을 가져간다.

## 2. 유저가 "안 들어오고는 못 배기는" 이유 (리텐션 훅)

1. **돈이 되는 알림** — 사고 싶은 물건이 목표가로 떨어지면 푸시가 온다. 알림 하나하나가 실질적인 이득이다.
2. **내 포인트가 쌓이는 걸 보고 싶다** — "구매확정 대기 1,240원"이 매일 늘어나는 걸 확인하러 들어온다.
3. **마감 임박 타이머** — 타임딜은 초 단위 카운트다운. 놓치면 손해라는 감각(FOMO).
4. **헌터 레벨 & 주간 랭킹** — 🌱새싹 → 👑레전드, 매주 월요일 리셋되는 시즌 랭킹.
5. **출석 스트릭** — 7일 연속 출석마다 보너스 포인트.
6. **"오늘 줍줍러들이 아낀 돈 8,372만원"** — 홈 상단 사회적 증거 배너.

## 3. 바이럴 루프 (스스로 성장하는 구조)

```
 [A가 핫딜 발견] ─ 링크 붙여넣기 → 자동으로 줍줍 제휴링크 변환
        │
        ▼
 [A가 카톡방/맘카페/인스타에 공유]  ← 공유 링크엔 A의 ref 코드 + 예쁜 공유 카드(할인율·온도)
        │
        ▼
 [친구 B가 클릭 → 줍줍 딜 페이지 방문] ── ref 쿠키 30일 저장
        │                      │
        │ 구매                  │ "나도 벌 수 있네?" → 가입 (초대자 = A)
        ▼                      ▼
 [A에게 수수료 30%]      [B도 딜을 공유하기 시작] → 루프 반복
                               │
                               └→ B가 벌 때마다 A에게 추가 보너스 10% (플랫폼 부담, 1단계만)
```

추가 루프:
- **크리에이터 채널 (SaaS)**: 인스타/유튜브/블로그 운영자에게 `jupjup.kr/@handle` 페이지를 준다. 팔로워가 여기서 구매하면 크리에이터에게 수익 공유.
  크리에이터가 자기 팔로워를 줍줍으로 데려오는 구조 → 유료 마케팅 없이 트래픽 유입.
- **공유 카드**: 딜마다 OG 이미지(할인율/가격/딜 온도)를 자동 생성 → 카톡 미리보기 클릭률 극대화.
- **앱 공유 타깃**: 쿠팡 앱에서 "공유 → 줍줍" 한 번이면 딜 등록 화면이 열린다(PWA share_target). 등록 마찰 최소화.
- **SEO**: 모든 딜 페이지가 서버 렌더 + sitemap → "상품명 최저가" 검색 유입.

## 4. 수익 구조

- 모든 구매 링크는 서버의 `/go/{id}`를 거쳐 **내 제휴 링크로 변환**된다. (타인 제휴 파라미터 제거 → 링크 하이재킹 방지)
- 클릭마다 고유 `clickId`를 제휴사 subId로 전달 → 실적 리포트의 subId로 공유자/게시자를 역추적 → 포인트 지급.
- 기본 분배(`src/lib/rewards.ts` `REWARD_POLICY`): 공유자 30% / 게시자 20% / 플랫폼 50% (초대 보너스 10%는 플랫폼 몫에서 지급).
- 셀프 구매(자기 공유 링크로 본인 구매)는 공유 리워드 제외.

### ⚠️ 제휴 약관 주의 (중요)
- **쿠팡 파트너스** 등 일부 프로그램은 리워드/캐시백형 구매 유도를 제한할 수 있다(오픈 전 최신 약관을 반드시 확인). 그래서 기본값으로 `merchants.ts`에서 쿠팡은 `rewardEligible: false`로 두고
  수수료 공유 대신 **XP/랭킹 보상만** 준다. 수익은 전액 플랫폼 몫이다.
- 링크프라이스 등 리워드 매체를 허용하는 네트워크나 광고주와는 **리워드 매체로 계약**한 뒤 `rewardEligible: true`로 켠다.
- 공정위 추천·보증 심사지침에 따라 딜 페이지 하단에 제휴 링크임을 고지한다(구현됨).
- 포인트 현금 출금은 기타소득 원천징수(건당 5만원 초과 시), 본인인증이 필요하므로 **출금 기능은 세무 검토 후 오픈**한다(현재 UI에 "오픈 예정" 표기).
