# 줍줍 디자인 원칙

## 1. 톤
- **정보가 주인공이다.** 화면의 색·장식보다 상품 이미지, 가격, 남은 시간, 포인트 같은 사실이 먼저 보인다.
- **한국어 우선.** 버튼·라벨·상태는 모두 한국어(WANTED/SPIN/TOP/MY 같은 영문 라벨 금지). 존댓말 해요체, 짧게.
- **장식 금지 목록**: UI 크롬(탭·버튼·제목)에 이모지 사용, 그라디언트 배경 카드, 과한 그림자·네온·반짝임 효과, 의미 없는 파스텔 색 나열, 느낌표 남발.
  이모지는 사용자가 만든 콘텐츠(닉네임, 캐릭터 꾸미기)에만 남는다.
- 아이콘은 한 세트(`components/Icon.tsx`, 24px 라인 아이콘, 1.8px 선)만 쓴다.

## 3. 사용자 여정별 화면 원칙
| 여정 | 사용자가 원하는 것 | 화면이 주는 것 |
|---|---|---|
| 처음 방문 → 딜 탐색 | 지금 싼 게 뭔지 빨리 | 홈: 검색 → 정렬 → 카테고리 → 딜 목록. 로그인 없이 구매까지 가능 |
| 딜 확인 → 구매 | 진짜 싼지 판단 | 상세: 가격·할인율·배송 → 판매처 이동(하단 고정) → 추천/비추천 수 → 가격 변동 → 댓글 |
| 원하는 상품이 있음 | 대신 찾아줬으면 | 수배: "무엇을, 얼마 이하로, 현상금 얼마" 3가지만 입력. 진행 상태(참여·발견·남은 시간) 한 줄 |
| 찾아서 보상받기(헌터) | 어디에 올리고 얼마 받나 | 수배 상세의 "상품 찾았어요" → 링크 붙여넣기 → 목표가 대비 차이 즉시 표시 |
| 포인트 확인·사용 | 얼마 있고 뭘 할 수 있나 | 혜택: 잔액 → 오늘 할 수 있는 일(체크리스트) → 놀이터 → 교환 |
| 로그인 유도 | 왜 가입해야 하나 | 행동하려는 순간(추천·수배·알림)에만 맥락과 함께 요청 |

## 4. 놀이터(게임) 원칙
- 몰입 장치(긴장감, 계속/멈춤 선택, 변동 보상, 아깝게 놓친 결과)는 쓰되 **카지노를 연상시키는 소재(슬롯·룰렛·칩·잭팟·네온)는 쓰지 않는다.**
  소재는 쇼핑·어린 시절 놀이(가격 맞히기, 뽑기 캡슐, 긁는 쿠폰)에서 가져온다.
- 게임 재화 "구슬"은 포인트·현금·상품권으로 바뀌지 않는다. 확률과 이론 환급률을 게임 화면에서 항상 볼 수 있게 한다.
